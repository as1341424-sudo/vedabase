# Bhaktivedanta VedaBase — Modern Desktop App

## Quick Start
```bash
python main.py
```

## Architecture
- **Runtime:** Python 3.11 + PyWebView 6.2
- **Database:** SQLite (folio.db — 1.6M+ records)
- **Frontend:** Vanilla JS + CSS (ISKCON dark-mode theme)

## Hotkeys
| Key | Action |
|-----|--------|
| F2  | Search overlay |
| F3  | Focus sidebar tree |
| F4  | Document view |
| Alt+← | History back |
| Alt+→ | History forward |

## DB Path
`data/folio.db` (auto-copied from Downloads on first run)
